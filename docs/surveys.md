# Формы (самочувствие, обратная связь, опросы)

Регулярные обязательные формы в личном кабинете. Управление — `/admin/surveys` (право `surveys.manage`),
результаты — `/admin/surveys/<id>/results` (право `surveys.results`). По умолчанию оба права у командира и комиссара.

## Быстрый старт

1. `/admin/surveys` → «Шаблоны» → «Самочувствие» → «Создать черновик из шаблона».
2. Проверьте вопросы и настройки, нажмите «Предпросмотр» — так форму увидит боец.
3. Отметьте «Форма активна» → «Сохранить». В начале периода бойцы получат уведомление (кабинет, Telegram/VK — по их
   настройкам).

## Настройки формы

| Раздел | Что настраивается |
|---|---|
| Вопросы | 7 типов: шкала (0/1…10, подписи краёв), один вариант, несколько вариантов, да/нет, короткий и развёрнутый ответ, число (границы). Обязательность, подсказка, порядок, копирование |
| Условие показа | «Показывать, если ответ на вопрос выше — один из …» (например, «Что беспокоит?» только при «Есть жалобы: Да») |
| Сигнал | Командному составу приходит уведомление, если ответ ≤ / ≥ / = / ≠ значению, выбран вариант или поле заполнено. Во внешние каналы — без текста ответа |
| Кому | Нижняя граница роли и необязательная верхняя (например, «только бойцы» — командный состав форму не получает) |
| Расписание | Начало, окончание (необязательно), «регулярно каждые N дней» или «однократно», срок на прохождение от начала периода |
| Обязательность | «Только напоминания» · «Баннер в кабинете и напоминания» · «После срока кабинет закрыт, пока форма не пройдена» (открыты только формы, «Безопасность» и «Помощь») |
| Напоминания | О начале периода; за 6/12/24/48/72 часа до срока; просрочившим; итоги периода командному составу («прошли N из M») |
| Приватность | Анонимно (ответ хранится без имени и без времени; видно только, кто прошёл); изменение ответа до конца периода; срок хранения ответов (30–1095 дней) |

После первых ответов **начало, периодичность и анонимность** заблокированы: иначе ответы перепутаются между
периодами. Нужно другое расписание — «Копировать» и запустить копию.

## Результаты

Период выбирается в списке. На странице: кто прошёл и кто нет, сработавшие сигналы, распределение ответов по каждому
вопросу, динамика средних по шкалам за последние 8 периодов, ответы по людям (кроме анонимных форм), кнопка
«Напомнить не прошедшим» (не чаще раза в час) и выгрузка CSV (Excel, разделитель «;») за период или за всё время.
Каждая выгрузка пишется в журнал аудита.

## Как это устроено

- Периоды считаются от «Начала»: номер = ⌊(сейчас − начало) / N дней⌋; срок = начало периода + «срок на
  прохождение». Отметка «прошёл» (`SurveyCompletion`) — одна на человека и период.
- Анонимная форма: ответ (`SurveyResponse`) без `userId`, `createdAt` = начало периода, в результатах и CSV порядок
  ответов перемешан.
- Воркер раз в минуту делает рассылки; каждая рассылка по периоду — ровно один раз (`SurveyDispatch`). Раз в час
  удаляет ответы старше срока хранения.
- Код: `packages/shared/src/surveys.ts` (схема вопросов, проверка ответов, периоды, шаблоны),
  `packages/core/src/surveys.ts` (приём ответов, рассылки, очистка), `apps/web/src/app/admin/surveys`,
  `apps/web/src/app/cabinet/surveys`, `apps/web/src/components/cabinet/survey-gate.tsx`.
