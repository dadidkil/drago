# Боты: Telegram и VK

Оба бота работают поверх общей БД: пользователи, права, мероприятия, задачи и заявки — те же, что на сайте.
Уведомления в мессенджеры отправляет воркер (`apps/worker`), а не боты.

## Telegram (grammY, long polling)

### Настройка

1. В @BotFather: `/newbot` → получите токен. Рекомендуемые настройки: `/setjoingroups` → Disable (бот работает
   только в личных сообщениях), `/setdescription`, `/setuserpic`.
2. В `.env` задайте `TELEGRAM_BOT_TOKEN=...` и `TELEGRAM_BOT_USERNAME=имя_бота` (без @). Затем `make deploy`.
3. Проверка: `/admin/integrations` → «Бот @… отвечает».

Режим long polling не требует открытого входящего порта и webhook.

### Привязка аккаунта

Кабинет → «Безопасность» → «Подключить Telegram». Кабинет генерирует одноразовую ссылку
`t.me/<бот>?start=link_<токен>`: токен 192 бита, действует 10 минут, в БД хранится хэш. Бот связывает аккаунт с
**числовым Telegram user ID** — username не используется. Один Telegram можно привязать только к одному аккаунту.
Отвязать можно командой `/unlink` или в кабинете.

### Команды

| Команда / кнопка | Кто | Что делает |
|---|---|---|
| `/start`, `/help` | все | приветствие, меню; привязанному — сколько дел ждёт действия |
| `/today`, «🔥 Мои дела» | привязанные | всё, что ждёт действия, — каждое дело отдельным сообщением с кнопками: задачи, сдачи на проверку, обязательные формы, приглашения без ответа, непрочитанная почта |
| `/profile` | привязанные | профиль (без телефона) |
| `/events`, «📅 Ближайшие мероприятия» | привязанные | мероприятия с кнопками «Иду / Возможно / Не смогу»; выбранный ответ отмечается в сообщении |
| `/tasks`, «✅ Мои задачи» | привязанные | мои задачи с кнопками «▶️ В работу / 📤 Сдать» |
| `/review`, «🧐 На проверку» | кто ставит задачи | сдачи, которые ждут моей проверки: «✅ Принять / ↩️ На доработку» (бот спросит, что доработать) |
| `/announcements`, «📣 Объявления» | привязанные | последние объявления для своей аудитории |
| `/documents`, «📄 Документы» | привязанные | список документов; скачивание — только в кабинете с проверкой прав |
| `/cabinet`, «🔗 Личный кабинет» | все | ссылка в кабинет |
| `/contacts` | все | контакты отряда |
| `/join`, «✍️ Вступить» | не привязанные | как вступить и кнопка «Подать заявку» — в приложение МосРСО во ВКонтакте (бот анкету не собирает) |
| `/participants` | `events.manage` | участники выбранного мероприятия |
| `/announce` | `announcements.manage` | мастер создания объявления: заголовок → текст → аудитория → подтверждение |

Критичные операции — пользователи, роли, удаление, почта, настройки — доступны **только** в веб-админке.

### Уведомления

Воркер присылает уведомления — многие сразу с кнопками действий, отвечать можно прямо из Telegram:

| Событие | Кому | Кнопки |
|---|---|---|
| Новая задача | исполнителям (и автору, если поставил себе) | «В работу», «Сдать» |
| Задача сдана | тому, кто поставил | «Принять», «На доработку» |
| Принято / возвращено на доработку | исполнителю | при возврате — «В работу», «Сдать» |
| Скоро срок (за 24 ч) / просрочено | исполнителям, кто ещё не сдал; о просрочке — и автору | «Сдать» |
| Новое мероприятие, приглашение | аудитории / приглашённым | «Иду», «Возможно», «Не смогу» |
| Изменение или отмена мероприятия, напоминание за 24 ч | участникам | — |
| Новое объявление, новый документ | своей аудитории | — |
| Новое письмо в корпоративном ящике | владельцу ящика | — |
| Обязательная форма, тревожный ответ в форме | аудитории формы / `surveys.results` | — |
| Утренняя сводка «Мои дела» (9:00 МСК) | только тем, у кого есть дела | — |

Логика задач общая для кабинета и бота (`packages/core/src/tasks.ts`): исполнитель сдаёт → принимает тот, кто
поставил (или командный состав с `tasks.manage` уровнем не ниже автора) → задача выполнена, когда принята у всех.
Права проверяются на сервере при каждом нажатии кнопки. Каналы и типы уведомлений каждый настраивает в кабинете:
«Профиль» → «Уведомления» (сводку можно выключить).

## VK (Callback API)

### Настройка сообщества https://vk.ru/top_drago

1. Управление → **Сообщения** → включить. **Настройки для бота** → «Возможности ботов» — включить, «Добавить кнопку
   „Начать“» — включить.
2. Управление → **Работа с API** → **Ключи доступа** → создать ключ с правом «Сообщения сообщества». Запишите его в
   `.env` → `VK_ACCESS_TOKEN`.
3. **Callback API**:
   - версия API: **5.199** (`VK_API_VERSION`);
   - адрес: `https://dragotop.ru/vk/callback`;
   - строка подтверждения из поля «Строка, которую должен вернуть сервер» → `.env` `VK_CONFIRMATION_CODE`;
   - секретный ключ: значение `VK_CALLBACK_SECRET` из `.env` (сгенерирован, ≥8 символов);
   - `VK_GROUP_ID` — числовой ID сообщества.
4. `make deploy`, затем в VK нажмите «Подтвердить».
5. Типы событий: **Входящее сообщение** (`message_new`), **Разрешение на получение** (`message_allow`),
   **Запрет на получение** (`message_deny`).

### Безопасность обработчика

- Принимается только `POST /vk/callback`, JSON до 64 КБ, с таймаутами.
- Проверяются `group_id` и `secret` — сравнение с постоянным временем. Без настроенного секрета отклоняются все запросы.
- На `confirmation` сервер возвращает строку подтверждения. На события сразу отвечает `ok`: VK ждёт ответ до 10 с и
  иначе повторяет доставку. Обработка идёт асинхронно.
- Повторная обработка исключена: `event_id` записывается в `ProcessedUpdate` (уникальный ключ), дубли пропускаются.
- Rate limit по IP на входящие запросы и по пользователю VK на сообщения; беседы игнорируются.

### Меню бота

«О Драго», «Вступить», «Ближайшие мероприятия», «Наши проекты», «Контакты», «Сайт».

**Вступить** присылает текст о наборе и ссылку на подачу заявки. Заявки в ТОП принимает только МосРСО в своём
приложении ВКонтакте, поэтому ни сайт, ни боты анкету не собирают. Ссылка задаётся в админке: «Страницы» →
«Главная и контакты» → «Ссылка «Подать заявку»» (по умолчанию —
`https://vk.ru/rso_mosrso_top?w=app5619682_-219801650`).

**Привязка VK к аккаунту:** кабинет → «Безопасность» → «Подключить ВКонтакте» → отправить сообществу
`привязать ABCD2345` (код одноразовый, действует 10 минут).
